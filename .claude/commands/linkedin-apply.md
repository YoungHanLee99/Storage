# 링크드인 구직 지원 워크플로

채용공고 하나를 받아 **분석 → 적합도 평가 → 지원 서류 작성 → 기록**까지 수행합니다.
입력: `$ARGUMENTS` (링크드인 공고 URL, 또는 붙여넣은 공고 본문)

> 링크드인은 로그인 없이 공고 본문을 읽을 수 없는 경우가 많습니다. 자동 조회가 막히면
> 사용자에게 공고 본문을 붙여넣어 달라고 요청하고, 추측으로 공고 내용을 채우지 마세요.

## 1. 공고 확보

- `$ARGUMENTS`가 비어 있으면 공고 URL 또는 본문을 요청하고 중단합니다.
- URL이면 WebFetch로 조회를 시도합니다. 로그인 벽·차단·빈 본문이면 즉시 사용자에게
  본문 붙여넣기를 요청합니다. (재시도 반복 금지)
- 확보한 공고에서 다음을 추출합니다. 없는 항목은 "미기재"로 남기고 지어내지 않습니다.
  - 회사명 / 직무명 / 팀 / 근무지·재택 여부 / 고용형태
  - 핵심 자격요건(필수) · 우대사항
  - 주요 업무(JD 원문 기준)
  - 마감일, 공고 게시일, 지원자 수(표시된 경우)
  - 공고에 반복 등장하는 키워드 (ATS 대응용)

## 2. 내 이력 자료 수집 — 독립적인 조회는 병렬로 실행

- **Google Drive**: 이력서·경력기술서·포트폴리오 검색 (`이력서`, `resume`, `CV`, `경력기술서`)
  → 가장 최신본을 읽어 내 경력·기술 스택·성과 수치를 파악합니다.
- **Google Drive**: 지원 기록 파일 `LinkedIn 지원 현황.md` 를 읽습니다. (없으면 3-1에서 생성)
  → **같은 회사·직무에 이미 지원했는지 먼저 확인**하고, 중복이면 사용자에게 알리고
  진행 여부를 묻습니다.
- **Gmail**: 해당 회사명으로 과거 메일 검색 → 이전 접촉·리크루터 연락 이력 확인.

## 3. 적합도 평가

- 공고의 필수 요건을 한 줄씩 나열하고 각각 **충족 / 부분 충족 / 미충족**으로 표시합니다.
  근거는 내 이력서의 실제 내용에서만 가져옵니다.
- 갭(미충족 항목)과 그 갭을 완화할 수 있는 인접 경험을 정리합니다.
- 종합 판단을 한 문단으로 제시합니다: 지원 권장 / 조건부 권장 / 비권장 + 이유.
- **비권장이어도 서류는 작성합니다.** 지원 여부는 사용자가 결정합니다.

## 4. 지원 서류 작성 (한국어 공고면 한국어, 영문 공고면 영어)

다음 네 가지를 모두 작성합니다.

### A. 맞춤 이력서 불릿
- 이 공고에 맞춰 재배치·재작성한 경력 불릿 5~8개.
- 공고 키워드를 자연스럽게 반영하되, **원본 이력서에 없는 경험·기술·수치를 새로 만들지 않습니다.**
  강조점 변경과 표현 조정만 허용합니다.
- 각 불릿은 `행동 + 방법 + 결과(가능하면 수치)` 형태로 씁니다.

### B. 커버레터 (300~450자 / 영문은 250~350 words)
- 1문단: 지원 직무와 지원 동기 — 회사·공고의 구체적 요소를 인용합니다.
- 2문단: 핵심 요건 2~3개에 대응하는 내 실제 경험.
- 3문단: 입사 후 기여 + 마무리.
- 상투어("열정적인", "빠르게 배우는") 대신 구체적 사실로 씁니다.

### C. 리크루터 DM 초안 (링크드인 메시지, 300자 이내)
- 커넥션 요청에 붙일 짧은 버전과, 이미 연결된 경우의 버전 두 가지.

### D. 예상 면접 질문 10개
- 공고 요건과 내 갭에서 도출한 질문 + 각 질문에 대한 답변 뼈대(불릿 3개).

## 5. 산출물 저장

- Google Drive에 `지원/{회사명}_{직무명}_{YYYY-MM-DD}.md` 로 저장합니다.
  (공고 요약 + 적합도 평가 + 서류 4종 전체를 한 파일에 담습니다.)
- 개인 구직 정보는 **이 git 저장소에 커밋하지 않습니다.** 저장 위치는 Drive입니다.

## 6. 지원 기록 및 후속 조치

- Drive의 `LinkedIn 지원 현황.md` 에 아래 형식으로 한 행을 추가합니다.
  파일이 없으면 헤더와 함께 새로 만듭니다.

  ```
  | 지원일 | 회사 | 직무 | 공고 URL | 상태 | 최근 업데이트 | 비고 |
  |---|---|---|---|---|---|---|
  | 2026-08-16 | 예시㈜ | 백엔드 엔지니어 | https://... | 지원예정 | 2026-08-16 | 서류 초안 작성 완료 |
  ```

  상태 값: `지원예정` / `지원완료` / `서류합격` / `면접중` / `최종합격` / `불합격` / `무응답`

- Google Calendar에 **지원 1주 후** 팔로업 리마인더 일정을 생성합니다.
  제목: `[구직] {회사} {직무} 팔로업 확인`
- 공고에 마감일이 있으면 **마감 2일 전** 리마인더도 생성합니다.

## 7. 사용자에게 보고

- 적합도 요약(3줄) → 작성한 서류 목록 → Drive 파일 링크 → 등록한 리마인더 순으로 보고합니다.
- **실제 지원 제출은 사용자가 직접 합니다.** 대신 제출하지 않으며, 임의로 메일·DM을
  발송하지 않습니다. 발송이 필요하면 초안만 만들고 확인을 받습니다.
