# 오전 브리핑 & 어제 타임리포트

매일 오전 9시(Asia/Seoul)에 실행하는 루틴입니다. 아래 순서대로 수행하세요.

## 1. 기준 날짜
- 오늘과 어제 날짜를 확정합니다. (타임존: Asia/Seoul)

## 2. 데이터 수집 — 독립적인 조회는 병렬로 실행
- **Gmail**: 받은편지함 미열람 메일 — 쿼리 `is:unread in:inbox newer_than:2d`
- **Slack — 받은 항목**: 어제 0시 이후 나에게 온 DM·멘션
- **Slack — 어제 내 활동**: 어제 내가 보낸 메시지 (`from:@me on:<어제 날짜>`)
- **Google Calendar**: 오늘 일정 + 어제 일정

## 3. 결과물 작성 (한국어, 간결하게)

### A. 오늘 할 일 브리핑
- 회신·승인·검토·확인이 필요한 항목만 추립니다.
- 제외: 광고/뉴스레터, 단순 알림, 자동 전달(FW) 사본, 이미 `[승인완료]`된 전자결재 통지, 일일매출보고서 등.
- 우선순위 순으로 정렬하고 각 항목에 출처(메일/슬랙)와 담당·마감을 표기합니다.
- 전자결재함의 **결재 대기**(결재경로에 승인일이 비어 있는) 건은 별도로 강조합니다.
- 오늘 회의·약속을 시간순으로 정리합니다.

### B. 어제 타임리포트
- 어제 캘린더 일정 + 슬랙 활동을 근거로 시간대별 업무 내역을 정리합니다.
- 업무를 분류(회의 / 계약·문서 검토 / 법무 이슈 / 커뮤니케이션·조율 / 학습 등)하고 대략의 소요 시간을 표기합니다.
- 시간은 기록에서 재구성한 추정치임을 명시합니다.

## 4. 전송
- 완성한 브리핑을 **본인 Slack DM**(나와의 대화)으로 전송합니다.
  채널 ID는 현재 로그인한 Slack 사용자 본인의 user_id를 사용합니다.
- 첫 줄 제목: `🗓 {오늘 날짜(요일)} 오전 브리핑`
- Slack 가독성을 위해 마크다운 헤더·표 대신 Slack mrkdwn(`*굵게*`, `_기울임_`, `•` 불릿)을 사용합니다.
