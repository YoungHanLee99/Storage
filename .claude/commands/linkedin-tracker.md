# 구직 지원 현황 점검

Drive의 지원 기록을 Gmail·캘린더 실제 이력과 대조해 **상태를 갱신하고 후속 조치를 뽑아냅니다.**
`$ARGUMENTS`에 회사명이 있으면 해당 건만, 없으면 전체를 점검합니다.

## 1. 기준 데이터 로드

- Google Drive에서 `LinkedIn 지원 현황.md` 를 읽습니다.
  없으면 "아직 지원 기록이 없습니다. `/linkedin-apply` 로 시작하세요."라고 안내하고 종료합니다.
- 오늘 날짜를 확정합니다. (타임존: Asia/Seoul)

## 2. 실제 이력 대조 — 독립적인 조회는 병렬로 실행

기록된 각 회사에 대해:

- **Gmail**: 회사명·도메인으로 검색해 지원 이후 도착한 메일을 확인합니다.
  - 서류 합격/면접 제안 → 상태 `서류합격` 또는 `면접중`
  - 불합격 통보 → 상태 `불합격`
  - 지원 접수 확인 메일만 있음 → 상태 `지원완료` 유지
- **Google Calendar**: 회사명이 포함된 향후 일정(면접 등)을 검색합니다.
- 자동 발송 광고·채용 뉴스레터는 회신으로 취급하지 않습니다.

## 3. 상태 갱신

- 근거가 확인된 건만 상태를 바꾸고, `최근 업데이트`를 오늘 날짜로 씁니다.
- 상태를 바꾼 건은 **비고에 근거를 한 줄 남깁니다** (예: `8/14 인사팀 면접 일정 회신`).
- 근거가 애매하면 상태를 바꾸지 말고 "확인 필요"로 사용자에게 보고합니다.
- 갱신한 표로 Drive 파일을 업데이트합니다.

## 4. 후속 조치 도출

- **무응답 경고**: `지원완료` 상태로 14일 이상 경과 → 팔로업 메일 초안을 제안합니다.
- **면접 임박**: 7일 이내 면접 일정 → 준비 항목(예상 질문 재확인, 회사 최근 뉴스)을 알립니다.
  해당 회사의 `지원/{회사명}_...md` 파일에 작성해 둔 예상 면접 질문을 함께 불러옵니다.
- **회신 필요**: 리크루터 메일에 아직 답장하지 않은 건 → 회신 초안을 제안합니다.
- **마감 임박**: `지원예정`인데 공고 마감이 3일 이내 → 강조 표시합니다.

## 5. 보고

한국어로 간결하게, 아래 순서로 정리합니다.

1. **요약 한 줄**: 총 N건 / 진행중 N / 대기 N / 종료 N
2. **오늘 조치 필요** — 우선순위 순, 각 항목에 회사·직무·해야 할 일·근거
3. **전체 현황표** — 상태별로 묶어서
4. **이번 주 면접·일정**

- 메일 회신이나 팔로업은 **초안만 작성**하고, 사용자 확인 없이 발송하지 않습니다.
