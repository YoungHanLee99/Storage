# 업무용승용차 비용처리 — 필요서류 체크리스트

> 관련 문서: [업무용승용차 비용처리 가이드](./업무용승용차-비용처리-가이드.md)
> 기준일: 2026년 9월
> ⚠️ 참고용 정리이며, 최종 신고는 세무대리인 확인을 거치십시오.

## 0. 지금 당장 확보해야 할 5가지

차량을 막 구매하신 시점에서, **시간이 지나면 재발급이 번거로워지는 순서**입니다.

1. **자동차등록증** — 배기량·승차정원·최초등록일 확인용 (업무용승용차 해당 여부 판정의 근거)
2. **차량 구입 세금계산서** (또는 매매계약서) — 취득가액의 원천
3. **취득세 납부영수증** — 취득가액에 가산
4. **공채(지역개발채권 등) 매입·즉시매도 영수증** — 할인차손이 취득가액에 가산됨. **가장 자주 누락되는 서류**
5. **할부·리스·렌트 계약서 + 원리금 상환 스케줄표** — 원금/이자 구분 자료가 없으면 이자비용 산정 불가

## 1. 취득 단계 — 취득가액을 확정하는 서류

| 서류 | 발급처 | 용도 | 구분 |
|---|---|---|---|
| 자동차등록증 | 차량등록사업소 / 등록대행사 | 배기량·정원·차종 → 업무용승용차 해당 여부 판정 | **필수** |
| 차량 구입 세금계산서 | 자동차 판매사 | 취득가액, 적격증빙 | **필수** |
| 자동차 매매계약서(신차 주문계약서) | 판매사 / 중고차 매매상사 | 차량가·옵션·인도일 | **필수** |
| 취득세 납부영수증 | 위택스 / 시·군·구청 | 취득가액 가산 | **필수** |
| 공채 매입·할인 영수증 | 은행 / 등록대행사 | 할인차손 취득가액 가산 | 권장 |
| 등록대행 수수료·탁송료 영수증 | 등록대행사 / 탁송업체 | 취득 부대비용 | 권장 |
| 옵션·용품 장착 영수증 | 판매사 / 장착점 | 취득 시 장착분은 취득원가, 이후는 당기비용 | 권장 |
| 대금 지급 증빙 (이체확인증·카드전표) | 은행 / 카드사 | 실제 지급 사실 입증 | **필수** |

> **취득가액 = 차량가 + 취득세 + 공채할인차손 + 등록 부대비용 + 불공제 부가세 + 취득 시 옵션**
> 위 서류들이 모두 모여야 이 금액이 확정되고, 여기에 5년 정액법이 적용됩니다.

### 1.1 취득 방식별 추가 서류

| 방식 | 추가로 필요한 서류 | 주의점 |
|---|---|---|
| **할부 · 오토론** | 할부금융(여신) 약정서, **원리금 상환 스케줄표** | 원금은 취득가액, **이자만 당기 관련비용** — 구분표가 없으면 산정 불가 |
| **금융리스** | 리스계약서, 리스료 구성내역서, 리스채무 상환표 | 자산으로 계상 후 감가상각 + 이자비용 |
| **운용리스** | 리스계약서, 월별 세금계산서, **리스료 구성내역서** | 리스료에서 보험료·자동차세·수선유지비를 차감해야 감가상각비 상당액 산출 → **구성내역서 필수** |
| **장기렌터카** | 렌트계약서, 월별 세금계산서 | 렌트료의 70%를 감가상각비 상당액으로 간주 (별도 구분 불필요) |
| **중고차** | 매매계약서, 성능·상태점검기록부, 이전등록 영수증 | 취득가액은 실제 매입가 기준 |

## 2. 보유·운행 단계 — 관련비용 증빙

| 항목 | 증빙 | 발급처 |
|---|---|---|
| 유류비 | 사업용 신용카드 전표 / 지출증빙용 현금영수증 / 세금계산서 | 주유소 |
| 자동차보험료 | **보험증권** + 보험료 영수증 | 보험사 |
| 자동차세 | 납부확인서 | 위택스 |
| 수리·정비비 | 세금계산서 / 카드전표 | 정비소 |
| 소모품(타이어·엔진오일 등) | 카드전표 / 현금영수증 | 판매점 |
| 통행료 | 하이패스 이용내역서 | 한국도로공사 |
| 주차비 · 세차비 | 카드전표 / 현금영수증 | – |
| 자동차 검사비 | 영수증 | 검사소 |

### 2.1 적격증빙 원칙
건당 **3만원 초과** 지출은 **세금계산서 · 계산서 · 신용카드매출전표 · 현금영수증(지출증빙용)** 중 하나를 받아야 합니다.
미수취 시 **증빙불비가산세 2%**가 부과됩니다.

> **실무 권장**: 차량 관련 지출은 **사업용 신용카드 한 장으로 통일**하십시오.
> 홈택스에 사업용 신용카드를 등록해 두면 사용내역이 자동 수집되어, 연말에 항목별로 집계하기가 가장 간편합니다.
> 개인 카드와 섞이면 업무 관련성 입증이 어려워집니다.

### 2.2 보험증권에서 확인할 것
차량이 **2대 이상**인 경우, 1대를 제외한 나머지 차량은 **업무전용자동차보험 특약**이 증권에 표기되어 있어야 합니다.
(1대뿐이라면 사업자 유형과 무관하게 확인 불필요 — 가이드 §4 참조)

## 3. 신고 단계 — 제출 또는 비치

| 서류 | 처리 | 근거 · 비고 |
|---|---|---|
| **업무용승용차 관련비용 명세서** | 종합소득세 신고 시 **세무서 제출** | 미제출·불성실 제출 시 **필요경비 산입액의 1% 가산세** (소득세법 제81조의14, 2022년 이후 과세연도) |
| **업무용승용차 운행기록부** | **비치·보관**, 세무서장 요구 시 제출 | 관련비용 1,500만원 초과 시 사실상 필수 → [양식](../../templates/운행기록부_양식.csv) |
| 감가상각비조정명세서 | 신고 시 제출 | 5년 정액법 강제상각 반영 |
| 고정자산(유형자산)대장 | 비치 | 차량운반구로 계상 |
| 감가상각비 한도초과 이월액 관리대장 | 내부 관리 | 다음 연도 이월 산입의 근거. **직접 관리하지 않으면 유실되기 쉬움** |

> 이월액 관리대장은 법정 서식이 아니지만, 800만원 한도초과액이 8~10년간 이어지므로
> 기장을 맡기더라도 **본인이 별도로 남겨 두는 것**을 권합니다. (`tools/vehicle_depreciation.py` 출력 활용)

## 4. 명의 관련

- 개인사업자는 **대표자 개인 명의 차량도 사업용 자산으로 계상 가능**합니다 (법인과 다른 점).
  다만 세금계산서를 **사업자등록번호로** 발급받아 두면 업무 관련성 입증이 훨씬 수월합니다.
- **공동사업장**은 공동사업장 또는 구성원 명의로 하되, 업무전용자동차보험의 "1대 제외" 판정은 **공동사업장을 1사업자로 보아** 적용됩니다.

## 5. 보관 기간

- 「국세기본법」 제85조의3: 장부 및 증거서류 **5년간 보존** (법정신고기한 다음 날부터 기산)
- 운행기록부도 동일하게 5년
- 다만 차량은 5년 상각 이후에도 **한도초과 이월액이 8~10년까지 이어지므로**,
  **취득 관련 서류(§1)는 이월액이 소진될 때까지 보관**하는 것이 안전합니다.

## 6. 최종 체크리스트

**취득 단계**
- [ ] 자동차등록증 사본
- [ ] 차량 구입 세금계산서 (사업자등록번호 발급분 권장)
- [ ] 자동차 매매계약서 / 주문계약서
- [ ] 취득세 납부영수증
- [ ] 공채 매입·할인 영수증
- [ ] 등록대행 수수료 · 탁송료 영수증
- [ ] 대금 지급 증빙 (이체확인증 / 카드전표)
- [ ] (할부·리스) 계약서 + 원리금 상환 스케줄표
- [ ] (운용리스) 리스료 구성내역서

**보유·운행 단계**
- [ ] 사업용 신용카드 홈택스 등록
- [ ] 자동차보험 증권 (2대 이상이면 업무전용 특약 확인)
- [ ] 자동차세 납부확인서
- [ ] 유류비·수리비·통행료·주차비 증빙 집계
- [ ] (관련비용 1,500만원 초과 시) 운행기록부 작성 개시

**신고 단계**
- [ ] 차량을 고정자산대장에 차량운반구로 계상
- [ ] 감가상각비조정명세서 작성
- [ ] **업무용승용차 관련비용 명세서 제출** (미제출 시 1% 가산세)
- [ ] 운행기록부 비치
- [ ] 한도초과 이월액 관리대장 갱신
