# 업무용승용차 운행기록부 작성 요령

> 근거: 「업무용승용차 운행기록 방법에 관한 고시」(국세청),
> 「소득세법」 제33조의2 제1항, 같은 법 시행령 제78조의3 제4항, 같은 법 시행규칙 제42조 제2항
> 관련 문서: [비용처리 가이드](./업무용승용차-비용처리-가이드.md) · [필요서류 체크리스트](./차량-비용처리-필요서류.md)
> ⚠️ 참고용 정리이며, 최종 신고는 세무대리인 확인을 거치십시오.

## 1. 먼저 판단 — 쓸 필요가 있는가

```
해당 과세기간 업무용승용차 관련비용 합계
   ├─ 1,500만원 이하  → 작성 불필요. 업무사용비율 100% 자동 인정
   └─ 1,500만원 초과  → 미작성 시 업무사용비율 = 1,500만원 ÷ 관련비용 으로 강제 축소
```

관련비용 = 감가상각비 + 유류비 + 보험료 + 자동차세 + 수선비 + 통행료 + 리스료/렌트료 + 금융리스 이자

### 1.1 작성의 실익 계산

```
작성 시 추가 인정액 = (관련비용 × 실제 업무사용비율) − 1,500만원
```

| 관련비용 | 미작성 시 비율 | 작성 시(90% 가정) | 추가 인정액 |
|---:|---:|---:|---:|
| 1,500만원 | 100% | 90% | **−150만원 (작성이 불리)** |
| 2,000만원 | 75% | 90% | +300만원 |
| 2,500만원 | 60% | 90% | +750만원 |
| 3,000만원 | 50% | 90% | +1,200만원 |

> **관련비용이 1,500만원 언저리면 작성하지 않는 편이 낫습니다.** 100%를 그냥 받기 때문입니다.
> 감가상각비에는 별도로 연 800만원 한도가 걸리므로, 실제 절세액은 위 추가 인정액보다 작을 수 있습니다.
> 정확한 비교는 `python3 tools/mileage_log.py <파일> --related-cost <금액>` 으로 확인하십시오.

## 2. 기재 항목

**기본정보** — 과세기간, 자동차등록번호, 차종

**운행내역** — 아래 항목을 건별로 기재

| 항목 | 내용 |
|---|---|
| 사용일자 | YYYY-MM-DD |
| 사용자(성명) | 실제 운전자 |
| 주행 전 계기판 거리 | 출발 시 계기판 누적거리(km) |
| 주행 후 계기판 거리 | 도착 시 계기판 누적거리(km) |
| 주행거리 | 주행 후 − 주행 전 |
| 업무용 사용거리 | **출퇴근용** + **일반업무용** 으로 구분 기재 |
| 비업무용 거리 | 개인 용도 주행 |
| 비고 | 방문지·목적 (선택이지만 소명력을 크게 높임) |

```
업무사용비율 = (출퇴근용 + 일반업무용) ÷ 총 주행거리
```

양식: [`templates/운행기록부_양식.csv`](../../templates/운행기록부_양식.csv)

## 3. 업무용 주행의 범위

**포함**
- **출퇴근** ← 가장 중요. 규칙적이고 입증이 쉬워 업무사용비율의 기반이 됩니다
- 거래처·대리점·지점 방문
- 회의·세미나 참석
- 판촉·영업 활동
- 교육·훈련 출석
- 업무 관련 출장

**제외**
- 주말·휴일 개인 용무, 여행
- 가족 행사, 병원 방문 등 사적 이동
- 업무와 무관한 야간·심야 주행

## 4. 실무 작성 요령

### 4.1 계기판 거리의 연속성이 가장 중요합니다

세무서가 가장 먼저 보는 것은 개별 주행의 목적이 아니라 **숫자가 이어지는지**입니다.

```
3/2  10,000 → 10,035   (35km)
3/3  10,035 → 10,120   (85km)   ← 이어짐 ✓
3/7  10,200 → 10,280   (80km)   ← 10,120~10,200 사이 80km가 공백 ✗
```

공백 구간은 **비업무용으로 추정**될 수 있습니다. 즉 기록하지 않은 주행은 불리하게 작용합니다.

### 4.2 매일 쓰지 않아도 됩니다 — 현실적인 운영법

건별로 매일 기록하는 것은 대부분 지속되지 않습니다. 아래 방식이 실효적입니다.

1. **월말 계기판 사진 촬영** — 매월 말일 계기판을 찍어 둡니다. 월간 총 주행거리가 확정됩니다.
2. **출퇴근은 정형화** — `편도 거리 × 2 × 출근일수`로 일괄 산정합니다.
   출퇴근은 매일 같은 경로이므로 이 방식이 오히려 신뢰도가 높습니다.
3. **비정기 업무 주행만 건별 기록** — 거래처 방문, 출장 등만 그때그때 메모합니다.
4. **나머지는 비업무용으로 처리** — 총 주행거리에서 ①②③을 뺀 잔여를 비업무용으로 잡습니다.

> 이렇게 하면 계기판 연속성이 자동으로 유지되고, 기록 부담도 월 1회 수준으로 줄어듭니다.
> 무엇보다 **잔여를 비업무용으로 인정하는 구조**라 과대계상 시비가 생기지 않습니다.

### 4.3 보조 증빙을 함께 남기십시오

운행기록부 단독보다, 교차 확인 가능한 자료가 붙을 때 신뢰도가 크게 올라갑니다.

| 보조 증빙 | 확인되는 것 |
|---|---|
| 하이패스 이용내역서 | 일자·시각·통행 구간 |
| 주유 카드전표 | 일자·주유 위치 |
| **캘린더 일정** | 거래처 미팅의 일시·장소 |
| 내비게이션 목적지 기록 | 실제 방문지 |
| 사업용 카드 사용처 | 이동 경로의 정황 |

> 캘린더를 업무 일정 관리에 쓰고 계시다면, **그 자체가 운행기록부의 근거 자료**가 됩니다.
> 연말에 캘린더를 내보내 운행기록부와 대조해 두면 소명 자료가 한 번에 완성됩니다.

### 4.4 업무사용비율은 몇 %가 적정한가

- **85~95%**: 무난한 구간. 출퇴근 + 통상 업무 주행이면 자연스럽게 이 범위가 나옵니다.
- **100%**: 개인 용도 차량이 **별도로 있음을 입증할 수 있을 때만** 주장하십시오.
  차량이 이 한 대뿐인데 비업무용 주행이 0km라면 가장 먼저 의심받습니다.
- 비업무용 거리를 **솔직하게 일부 계상하는 편이** 전체 기록의 신뢰도를 높입니다.

### 4.5 자주 부인당하는 유형

- 총 주행거리 대비 업무사용비율이 비현실적으로 높음 (특히 100%)
- 주말·공휴일 주행이 전부 업무용으로 기재됨
- 계기판 거리가 이어지지 않거나 역행함
- 연말에 소급해 일괄 작성한 정황 (동일 필체, 일괄 입력된 데이터)
- 사업장 소재지와 무관한 지역의 반복 주행
- 사용자란이 공란이거나 사업과 무관한 사람으로 기재됨

## 5. 검증 도구

작성한 CSV의 정합성을 기계적으로 확인할 수 있습니다.

```bash
# 정합성 검증 + 업무사용비율 산출
python3 tools/mileage_log.py 2026_운행기록부.csv

# 관련비용과 함께 — 작성 여부에 따른 효과 비교
python3 tools/mileage_log.py 2026_운행기록부.csv --related-cost 25000000
```

검사 항목
- `주행후 − 주행전 = 주행거리` 일치 여부
- `출퇴근용 + 일반업무용 + 비업무용 = 주행거리` 일치 여부
- 계기판 연속성 (공백·역행 탐지)
- 사용일자 정렬
- 업무사용비율 산출 및 100% 초과 여부 경고

## 6. 보관 및 제출

- **비치·보관**: 세무서에 정기 제출하는 서류가 **아닙니다**. 보관하고 있다가 관할 세무서장이 요구하면 **즉시 제출**합니다.
- **보관 기간**: 5년 (「국세기본법」 제85조의3)
- 종합소득세 신고 시 제출하는 것은 **「업무용승용차 관련비용 명세서」**이며, 운행기록부는 그 명세서상 업무사용비율의 근거가 됩니다.
- 차량별로 각각 작성합니다. 2대 이상이면 통합 작성할 수 없습니다.
