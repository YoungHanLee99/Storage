## 1. 사건 포트폴리오 (핵심 — 5~8건)

각 사건마다 아래 블록을 복제해 채웁니다. 기밀 유지를 위해 회사명·인명은 익명화하되 **유형·규모·본인 역할은 반드시 특정**합니다.

### 사건 #1

| 항목 | 내용 |
|---|---|
| **유형** | ☐ Fraud(횡령·배임) ☐ 부패·리베이트 ☐ 이해상충 ☐ 정책위반 ☐ 직장 내 괴롭힘 ☐ 성희롱 ☐ 차별·보복 ☐ 기타 |
| **인지 경로** | ☐ 제보채널 ☐ 익명제보 ☐ 감사 적발 ☐ 데이터 이상징후 ☐ 외부기관 통보 ☐ 기타 |
| **조직 규모 / 사건 규모** | (임직원 수 / 관련 금액 / 관련 인원 수) |
| **본인 역할** | ☐ 단독 수행 ☐ 조사 주도(팀 구성) ☐ 공동 수행 ☐ 감독·검토 ※ *앞의 두 개가 아니면 필수요건 ③ 미충족으로 읽힘* |
| **조사 기간** | |
| **① 착수 판단** | 어떤 근거로 조사 착수를 결정했는가. 착수하지 않기로 한 판단 기준은? |
| **② 조사 계획** | 범위(scope) 설정 기준, 증거보전 조치 여부, 조사팀 구성 |
| **③ 인터뷰** | 총 ___회 / 대상자 순서를 어떻게 정했는가 / 사전 고지 사항 / 난관과 대응 |
| **④ 증거·데이터** | 검토한 데이터 종류(이메일·메신저·결재·거래·정산·로그·출입·HR) / 총 ___건 / **어떤 가설을 세워 어떤 데이터를 요청했는가** |
| **⑤ 분석·결론** | 진술 충돌을 어떻게 해소했는가 / 증거 충분성 판단 / 최종 결론 |
| **⑥ 보고** | 보고 대상(경영진·이사회·감사위원회·규제기관) / 보고서 분량·형식 |
| **⑦ 권고·조치** | 징계 권고 / 제도 개선 / 형사고소·고발 / 규제기관 신고 여부 |
| **⑧ 종결 및 사후** | 실제 조치 결과 / 이의제기·역소송 유무와 대응 / 재발 여부 |
| **⑨ 난도 요소** | 무엇이 이 사건을 "복잡하고 민감"하게 만들었는가 (대상자 직급 / 정치적 민감성 / 증거 부족 / 다국적 / 시한 압박) |
| **⑩ 한 줄 요약** | *경력기술서에 들어갈 1~2문장. 주어는 "내가", 숫자 포함, 종결까지 서술* |

> 사건 #2 ~ #8은 위 표를 복제해 사용.

## 2. 사건 포트폴리오 커버리지 점검

포트폴리오 작성 후, 아래가 **모두 최소 1건씩** 채워졌는지 확인합니다. 빈칸이 있으면 해당 유형 사건을 찾아 추가하거나, 없다면 면접에서 어떻게 보완 설명할지 미리 정합니다.

| **HR 조사(괴롭힘·성희롱·차별·보복)** ※ 공고 명시 항목 | | ☐ |
| 이해상충 사안 | | ☐ |
| **단독 수행하여 종결한 사건** (필수요건 ③) | | ☐ |
| **데이터 기반으로 결론이 바뀐 사건** (필수요건 ⑤ — 최대 갭) | | ☐ |
| 조사 대상이 임원급이었던 사건 (독립성·압력 저항) | | ☐ |
| 해외·다국적 요소가 있던 사건 | | ☐ |

## 3. 상시 기능 경험 (사건 단위가 아닌 것)

| 항목 | 내용 | 대응 요건 |

| 조사 기준·매뉴얼 수립 | 제정·개정한 규정 / 조사 프로세스 표준화 | 직무소개 ④ |

| 데이터 분석 도구 | 직접 사용(SQL·Excel 고급·BI 툴) 또는 분석 요청·검증 경험 | 우대③ |
| 디지털 포렌식 / eDiscovery | 내부 수행 / 외부 벤더 관리 / 선정·감독 경험 | 업무내용 ② |
| 규제기관 대응 | 공정위·고용노동부·개인정보위·금감원·수사기관 등 | 우대② |
| 해외 법인 지원 | 국가 / 지원 방식 / 현지 자문 확보 구조 | 업무내용 ⑦ |
| 경영진·이사회 보고 | 보고 주기 / 형식 / 감사위원회 직보 여부 | 필수⑦ |
| 영어 업무 환경 | 영문 보고서 작성 / 영어 인터뷰 / 본사 대응 | 필수⑨ |

## 5. 자가 점검 — 제출 전 최종 확인

- [ ] 경력기술서 모든 문장의 주어가 "내가"인가? ("법무팀이", "회사가" 금지)
- [ ] 각 사건에 숫자(건수·기간·금액·인원)가 들어갔는가?
- [ ] "조사 → 결론 → 권고 → **실제 조치**"까지 연결된 사건이 2건 이상인가?
- [ ] HR 조사 경험이 전면에 배치되었는가?
- [ ] 12년 경력 계산이 공고 요건(Investigation/Compliance/Audit/Risk)에 부합하게 산정·표기되었는가?
- [ ] 변호사 자격이 첫 페이지에 보이는가?
- [ ] 영문 CV가 준비되었는가?
- [ ] C-level → IC Principal 지원에 대한 3문장 해명 스크립트가 준비되었는가?
